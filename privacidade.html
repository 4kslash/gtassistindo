Política de privacidade

Última atualização: 18 de novembro de 2026.

Esta política vale para o "GTA Assistindo Publicador", ferramenta de uso próprio do canal GTA Assistindo no YouTube.

Quais dados são acessados

Com a autorização do dono do canal (login do Google), a ferramenta acessa a conta do YouTube do próprio canal para enviar vídeos, miniaturas, legendas e itens de playlist, e para consultar o status desses vídeos. Ela não lê dados de outros usuários, de inscritos ou de comentários.

Como são usados e guardados

O token de acesso fica guardado só no computador do dono do canal. Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou enviado a outros servidores além dos do Google e do YouTube.

Serviços do Google

A ferramenta usa os Serviços de API do YouTube. Ao usá-la, valem também os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
